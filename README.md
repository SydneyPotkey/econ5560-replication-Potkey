# econ5560-replication-Potkey

Replication package for ECON 5560. It reproduces the experimental-auction (Tobit) willingness-to-pay estimates in Table 6 of Wei, Khachatryan, and Rihn (2021) using the authors' raw data.

## Paper

Wei, X., Khachatryan, H., & Rihn, A. (2021). Estimating willingness-to-pay for neonicotinoid-free plants: Incorporating pro-environmental behavior in hypothetical and non-hypothetical experiments. *PLoS ONE*, 16(5), e0251798. https://doi.org/10.1371/journal.pone.0251798

## Data

The data come from the [Harvard Dataverse archive](https://doi.org/10.7910/DVN/XCG1N8) identified in the paper's Data Availability Statement. Our team downloaded the data on September 23, 2026. The file `SPA_combined_sample.xls` is exactly as downloaded, with no edits.

The archive also contains `CE_combined_sample.xls`, the discrete-choice-experiment data. It is not included here because our code replicates only the auction results, and the 30 MB file is larger than GitHub's web-upload limit.

## How to run

You need R (version 4.6.1 was used) and the `readxl` package. Download the repository with the green **Code** button—either clone it or download and unzip the ZIP file. From a terminal inside the repository folder, run:

```bash
git clone https://github.com/SydneyPotkey/econ5560-replication-Potkey.git
cd econ5560-replication-Potkey
Rscript -e 'install.packages("readxl", repos="https://cloud.r-project.org")'
Rscript run_all.R > run_log.txt 2>&1
```

The script must be run from the repository's top-level folder because it uses relative paths. If you prefer RStudio, restart R, set the working directory to the repository folder with **Session → Set Working Directory → Choose Directory**, and run this in the console:

```r
system("Rscript run_all.R > run_log.txt 2>&1")
```

The script creates any needed output folders if they are missing.

## Files

- `run_all.R` — master script that loads the data, estimates the Tobit model and WTP for each subgroup.
- `SPA_combined_sample.xls` — second-price auction data from Harvard Dataverse, unmodified.
- `output_table.tex` — LaTeX table from the team write-up that places the paper's original numbers beside ours. It is not generated by the code, and its replication numbers come from an earlier version of the script.
- `run_log.txt` — full log from a clean run from a freshly downloaded copy of this repository, ending with `sessionInfo()`.
- `logs/` — folder containing log files.

## What did not fully replicate

The point estimates replicate closely, but the standard errors do not. For the full sample, the paper reports WTP of 0.250 (SE 0.079) for the neonicotinoid-free text label, 0.489 (0.087) for the logo, and −0.099 (0.085) for the treated label. We obtain 0.208 (0.146), 0.455 (0.157), and −0.122 (0.160), respectively.

The subgroup results follow the same pattern: signs and magnitudes are similar, but our standard errors are roughly 1.3 to 2.1 times larger (usually about 1.8 times). As a result, many of the paper's significance stars do not appear in our table. For example, the paper's text-label WTP for the regulation-agree group is 0.512***, while ours is 0.415*.

We believe this gap comes from choices the paper does not fully document:

1. We omitted the between-individual random effect (the Cᵢ term in equation 2), because the paper does not explain how it is estimated. Our model is a pooled Tobit.
2. We used a dummy variable for each plant code rather than the paper's plant-type attributes, because the data did not include a dictionary mapping plant codes to types.
3. We calculated WTP standard errors using the delta method with a numerical gradient, and assessed significance with two-sided normal z-tests. The paper does not explain how it calculated either.
4. For the labeling-importance subgroups, we dropped respondents with a missing `att_importance` value.

The team's original script also used a data path that existed only on one teammate's computer (`C:/Users/...`) and did not save its results to a file. Both issues were fixed in `run_all.R`.
